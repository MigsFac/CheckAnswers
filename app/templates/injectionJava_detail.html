Information - 基本情報

  • 対応ブラウザ：Google Chrome,Safari

Feature - 主な機能

  • 小児の放射性医薬品の投与量計算

Release notes - リリースノート

v1.0.0 (2024-12)
  • リリース

Target - 対象

  • 小児の放射性医薬品投与量を計算したい方

Purpose - 目的

投与量の計算のミスを無くし、妥当性を確認する。

Concept - コンセプト

計算には薬品ごとのクラス、基本量、最小量の与えられた表１および体重別・クラス別の表２から計算する必要があるため、計算ミスをなくすことを第一に考えました。以前VBAで作ったものをJavaで作り直しました。

Difference - 他アプリとの差異

使用シーンが限定されるため、類似アプリは少ないです。値の補完の考え方は施設により異なるため、自施設用としてカスタマイズできました。

Technique - 使用技術

  • HTML/CSS
  • JavaScript
  • Java
  • Spring Boot

Reasons - 技術の選定理由

学習のためにJavaを選択。フレームワークは軽量かつ高速で学習コストも低いSpring Bootを選択。

Team - チーム構成

Issues - 課題

Outlook - 今後の展望
