Glossary

「用語集登録・閲覧アプリ」

実際のデモはこちらからご覧いただけます。

Information - 基本情報

  • リリース日：2024年10月
  • 対応ブラウザ：Google Chrome,Safari

Feature - 主な機能

  • 用語集
  • csvファイルから用語登録
  • カテゴリや読み仮名で区分け

Release notes - リリースノート

v1.0.0 (2024-10)
  • リリース

Target - 対象

  • G検定に出てくる用語を知りたい方

Purpose - 目的

自分が学習した用語を復習すること。

Concept - コンセプト

カテゴリ別、読み仮名別にすることで用語を入力することなく探しやすくし、csvファイルを読み込むことで他の勉強にも対応できるようにしました。

Difference - 他アプリとの差異

独自の用語集を作ることができ、ジャンル別や読み仮名別で用語を探すことができます。

Technique - 使用技術

  • HTML/CSS
  • JavaScript
  • Python
  • Flask
  • SQLite

Reasons - 技術の選定理由

G検定の勉強の一環として、Pythonを選びました。フレームワークは軽量かつシンプルなFlask、データベースは扱いやすく軽量なSQLiteを選択。

Team - チーム構成

  • １人

Period - 開発期間

  • 2ヶ月

Issues - 課題

作成する物のイメージはできていたため障害は少なかったですが、カテゴリを二重構造にするのに少し手間がかかりました。何より用語の準備に時間がかかりました。

Outlook - 今後の展望

用語集の登録・編集を汎用的に行えるように対応する。ユーザーに対する使用性を検討する。

FAQ - よくある質問

Q: このアプリは無料ですか？
A: はい、無料でご利用いただけます。
