CheckAnswers

「問題集の答え合わせ用アプリ」

実際のデモは こちらからご覧いただけます。

Information - 基本情報

  • リリース日：2024年10月
  • 対応ブラウザ：Google Chrome,Safari

Feature - 主な機能

  • 問題集の答え合わせ
  • タイマー機能
  • 回答一覧表示および該当番号へのジャンプ
  • 結果の記録（日付、正解率、間違った問題番号、気になる問題番号）
  • CBT方式の練習

Release notes - リリースノート

v1.0.0 (2024-10)
  • リリース

Target - 対象

  • 問題集の答え合わせをする時間がもったいない方
  • CBT方式の受験勉強に書籍の問題集を用いている方

Purpose - 目的

このアプリを使用することで、答え合わせの手間や時間を削減し効率的な学習を支援します。また、CBT方式の練習を支援します。

Concept - コンセプト

反復が必要な問題集の答え合わせを自動化することで、手間や時間を削減することを第一に考えました。webアプリとすることで答え合わせの効率化とCBT方式の受験練習を兼ねることを実現しました。そのために必要な便利機能を付随させていくことで学習支援を達成しました。

Difference - 他アプリとの差異

実際の問題集アプリや自分で問題集を作るアプリは多々ありますが、任意の問題集の答え合わせができ、CBT方式の練習ができるものは見つけられませんでした。

Technique - 使用技術

  • HTML/CSS
  • JavaScript
  • Python
  • Flask
  • SQLite

Reasons - 技術の選定理由

当時、G検定の勉強を行っていたため、後々AI関係のプログラムに対応できるように勉強したいと思いPythonを選びました。アプリ自体は小規模のため、フレームワークに軽量かつシンプルなFlask、データベースにはSQLiteを選択。

Team - チーム構成

  • １人

Period - 開発期間

  • 2ヶ月

Issues - 課題

問題自体がないため、問題ページは不要で番号管理だけでよかったのですが、逆にページで切り替えられないため番号の切り替えや選択した回答の保持に苦慮しました。Flaskのsessionを使うことで対応しましたが、問題数が多くなると保存方法を考える必要があると思いました。また、思っていた以上にブラウザ間の差が大きかったです。

Outlook - 今後の展望

他のブラウザへの対応、ログイン機能の強化。他者に使ってもらうためのブラッシュアップや提供方法の検討を行い、次に繋げていきたいと考えています。
